# Paper Polish Checklist

Copy and track when running a full polish pass.

```text
Polish Progress:
- [ ] Contribution type identified (Insight / Performance / Capability)
- [ ] Contribution stated clearly in abstract/intro
- [ ] Each section maps to a contribution facet
- [ ] Orthogonal/tutorial content flagged or removed
- [ ] Reverse outline completed for target section(s)
- [ ] One idea per paragraph
- [ ] Paragraph openings state the paragraph job
- [ ] Paragraph closings hand off to next idea
- [ ] Simple language pass (short sentences, minimal jargon)
- [ ] Active voice pass
- [ ] Pronoun/relative-reference pass (this/that/which/they)
- [ ] Continuation markers at section openings
- [ ] Terminology consistent across edited text
- [ ] LaTeX commands/citations/math preserved
- [ ] Claims not accidentally strengthened without evidence
- [ ] Page-1 / teaser figure checked (if applicable)
```

## Per-Paragraph Micro-Check

For each paragraph under review:

1. Can I summarize it in one phrase?
2. Does the first sentence state that phrase?
3. Can I reverse-outline it in ≤3 bullets?
4. Does every sentence connect (cause, contrast, consequence, refinement, example)?
5. Are all `this/that/which/they` references unambiguous?

If any answer is "no", split or rewrite.

## Per-Section Opening Micro-Check

1. Does the opening say what the section will present?
2. Does it say why that matters for the paper's contribution?
3. Could a reviewer skip here and still re-enter later?

## Red Flags (Often Need Substantial Change)

- Reader cannot state the contribution after the intro
- Related work reads like a survey unrelated to differentiation
- Method section teaches a baseline in depth but under-explains the novel part
- Experiments section reports numbers without tying back to claimed contribution
- Multiple unrelated ideas in one paragraph
- Long passive chains in algorithmic description
